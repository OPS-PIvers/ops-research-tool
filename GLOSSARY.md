# OPS Research Tool

Student research for History Day and the 8th-grade capstone. Students capture
sources and passages on the web, then cite and annotate them for a bibliography.

## Language

**Source**:
One web page, article, book, PDF or primary document a student is using in a project.
_Avoid_: Page, reference, item

**Highlight**:
A passage a student captured from a source, tagged with a category and optionally a short note.
_Avoid_: Evidence, note, annotation, quote, mark

**Ready**:
A source that meets every requirement the teacher set for the project (citation, primary or secondary, annotation, highlights per source).
_Avoid_: Complete, done, finished

**Annotation**:
The paragraph a student writes about a whole source, printed under its citation in the annotated bibliography.
_Avoid_: Note, summary, using "annotations" for highlights
